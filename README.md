# MCP Demo

A runnable, production-grade series of demos teaching the Model Context Protocol (MCP) —
from building your own server to securing one with Keycloak, federating identity from LDAP,
and integrating with an AI/ML platform.

## Use cases

| # | Use case | Status |
|---|---|---|
| 1 | [Build your own MCP server](use-case-1-custom-server/) — stdio transport, 3 internal-tooling tools | ✅ Done |
| 2 | Keycloak-secured MCP server — OAuth 2.1/OIDC, scope-based RBAC | Coming soon |
| 3 | LDAP + Keycloak + WildFly — identity federation fronting a legacy Java EE app | Coming soon |
| 4 | MCP + Open Data Hub — a tool calling a model served on OpenShift | Coming soon |

Each use case is self-contained with its own README (how to run it) and IMPLEMENTATION.md
(what was built, step by step).
