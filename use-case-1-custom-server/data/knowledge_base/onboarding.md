# New Engineer Onboarding

Welcome to the platform team. Your first week checklist:

1. Request access to the internal VPN and the `platform-eng` LDAP group.
2. Clone the `infra-tools` repository and run `make setup`.
3. Join the #platform-eng and #incidents Slack channels.
4. Shadow an on-call engineer for one rotation before joining the rotation yourself.

If you get stuck, ask in #platform-eng-help — someone will respond within a few hours.
